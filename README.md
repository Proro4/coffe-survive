# Втеча на каву

Мережева міні-гра на canvas. Сервер лише віддає сторінку й пересилає стан гравців,
а вся симуляція (машини, ТЦК, боти) працює в браузері того, хто почав матч.

## Запуск на своєму комп'ютері

```
npm install
npm start
```

Гра відкриється на http://localhost:3000.

Щоб швидко дати лінк друзям без хостингу, у другому терміналі запусти:

```
npx cloudflared tunnel --url http://localhost:3000
```

Cloudflare видасть публічну адресу виду `https://....trycloudflare.com`. Вона працює, поки відкрито термінал.

## Постійний хостинг на Render (безкоштовно)

1. Залий цю папку в новий репозиторій на GitHub (без `node_modules`).
2. На render.com: New → Web Service → обери репозиторій.
3. Build Command: `npm install`, Start Command: `npm start`, план Free.
4. Після деплою отримаєш адресу `https://<назва>.onrender.com`. Це і є лінк на гру.

На безкоштовному плані сервер «засинає» після 15 хвилин без гравців, тож перше відкриття може тривати до хвилини.

## Кімнати

Усі, хто відкрив той самий лінк, потрапляють в одне лобі. Для окремої компанії додай до адреси `?room=назва`,
наприклад `https://<назва>.onrender.com/?room=druzi`.
